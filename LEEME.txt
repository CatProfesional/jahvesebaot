CATÁLOGO CORREGIDO PARA GITHUB PAGES

IMPORTANTE:
Todos los archivos están en una sola carpeta y las rutas ya están corregidas.

PARA REEMPLAZAR EL SITIO:
1. Borra los archivos actuales del repositorio o crea un repositorio nuevo.
2. Descomprime este ZIP.
3. Sube TODOS los archivos directamente a la raíz del repositorio.
4. Debes ver index.html, style.css, app.js y todas las imágenes juntos.
5. Espera 1–3 minutos y recarga con Ctrl + F5.

No subas la carpeta contenedora; sube lo que está dentro.
